 
# 💰 SpendWise – Smart Expense Tracker

### 📊 Track Smarter • Spend Better • Save More

**SpendWise** is an interactive expense tracking and financial analytics web application developed using **Python, Streamlit, SQLite, Pandas, and Plotly**.

It helps users record income and expenses, visualize spending patterns, manage monthly budgets, and understand their finances through interactive dashboards.

### 🌐 Live Demo

🚀 **[Explore SpendWise Live](https://spendwise-smart-expense-tracker-e3eofugtncoma8gr7qvspd.streamlit.app/)**

## ✨ Key Features

- 💵 **Income & Expense Tracking** – Add and manage daily transactions.
- 📊 **Interactive Dashboard** – Visualize income, expenses, balance, and savings rate.
- 📈 **Financial Analytics** – Explore category-wise and monthly spending charts.
- 🎯 **Budget Planner** – Set monthly category budgets and track spending.
- ⚠️ **Budget Alerts** – Get warnings when spending approaches or exceeds limits.
- 🔍 **Transaction Management** – Filter, view, and delete transactions.
- 📥 **CSV Export** – Download transaction records.
- 🎨 **Modern Interface** – Responsive Streamlit dashboard with custom styling.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/SpendWise-Smart-Expense-Tracker.git
```

**2. Navigate to the project**

```bash
cd SpendWise-Smart-Expense-Tracker
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 🚀 Deployment

The application is deployed using **Streamlit Community Cloud**.

🌐 **Live Application:** https://spendwise-smart-expense-tracker-e3eofugtncoma8gr7qvspd.streamlit.app/

**Note:** This public demonstration uses local SQLite storage. Data may reset after cloud restarts, and the app does not provide separate private user accounts. Please use sample data rather than sensitive financial information.
